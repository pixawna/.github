# SuperPlane

SuperPlane is an **open source DevOps control plane** for defining and running **event-based workflows**
across the tools you already use (Git, CI/CD, observability, incident response, infra, notifications, etc).

## Start here

- **Try it (demo)**: Follow the docs [Quickstart](https://docs.superplane.com/get-started/quickstart/).
- **Install for real**: See the [Installation overview](https://docs.superplane.com/installation/overview/).

## Repositories

- **[`superplanehq/superplane`](https://github.com/superplanehq/superplane)**: Core application (workflow engine + UI + CLI).
- **[`superplanehq/docs`](https://github.com/superplanehq/docs)**: Documentation site sources.
