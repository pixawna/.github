# SuperPlane

## One-shot 30% of engineering tasks.

SuperPlane lets AI agents fully automate routine development work. Free your
team to focus on what’s important.

SuperPlane is an open source AI software factory for high-confidence routine
work. It coordinates coding agents, source control, CI, review, approvals, and
feedback in one visible system—turning focused issues into verified,
review-ready pull requests without engineers having to manage every step.

## How it works

- **Discover** — Scan your codebase and backlog to find work that can be
  automated with high confidence.
- **Control** — Apply the same allowed scope, required checks, review policies,
  approvals, and escalation paths to every agent run.
- **Verify** — Feed failures back to the agent, rerun the required checks, and
  return work for review when it is ready.

Start with focused bugs, maintenance work, paper cuts, test fixes,
documentation updates, and small improvements with a clear outcome.

## Built around your engineering system

Keep the coding agents, source control, CI, and review tools your team already
trusts. Choose your models, run in the cloud or on-prem, and build your software
factory on the Apache 2.0 open source engine.
